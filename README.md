 # Machine Learning y Data Science

Repositorio organizado por etapas del aprendizaje y por tipo de problema.

## Estructura

- `00_Fundamentos/`: introducción a NumPy, Pandas y Matplotlib.
- `01_Preparacion_y_Exploracion/`: visualización, división, preparación de datos, pipelines, evaluación y selección de características/modelo.
- `02_Modelos_Supervisados/`: regresión lineal, regresión logística, SVM, árboles, Random Forest y Naive Bayes.
- `03_Modelos_No_Supervisados/`: KMeans, DBSCAN, distribución gaussiana, Isolation Forest y redes neuronales para detección de fraude.
- `datasets/`: conjuntos de datos usados por los notebooks.

## Notas

- Los notebooks quedaron reubicados una carpeta por tema para que el repositorio sea más fácil de navegar.
- Las rutas de datos locales dentro de las celdas de código se ajustaron a `../datasets/`.
- El notebook de regresión lineal que estaba en un subrepositorio separado ya quedó integrado en esta estructura.

## Uso rápido

1. Instala dependencias con `pip install -r requirements.txt`.
2. Abre el notebook que quieras ejecutar desde su carpeta temática.
3. Verifica que la ruta de los datos siga apuntando a `../datasets/`.
